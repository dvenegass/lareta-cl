# Fuentes para la imagen de vista previa

`share_image.py` dibuja la imagen que aparece al compartir una junta (WhatsApp, etc.).
Para que use la misma fuente que la web, copia aquí estos dos archivos de
[DM Sans](https://fonts.google.com/specimen/DM+Sans) (licencia libre OFL):

- `DMSans-Regular.ttf`
- `DMSans-Bold.ttf`

Si no están, se usa una fuente del sistema (Segoe UI en Windows, DejaVu Sans en
Linux, Arial en Mac). En un servidor Linux sin fuentes, instala `fonts-dejavu-core`.
